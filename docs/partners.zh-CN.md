## 为什么赞助 EdgeEver

* **高粘性生产力与知识创作者受众**：EdgeEver 汇聚了大量深度的开发者、自托管极客、研究者与知识管理工作者，用户群体对云存储、算力平台、开发工具及 AI 服务具有天然的高需求与长生命周期价值。
* **全球化多端全栈矩阵**：覆盖 macOS、Windows、Linux 桌面端，iOS（Swift 原生）与 Android 移动端，以及 Docker / Cloudflare Serverless 双运行时架构，品牌影响力具备跨平台与全球化传播力。
* **原生 AI Agent 与 MCP 生态先锋**：深度融合 Model Context Protocol（MCP）与 Agent 协同，处于当下 AI 工具与开发者基础设施大爆发的核心叙事交汇点。

## 我们接受的支持

我们欢迎并支持以下形式的深度合作：

* **直接财务赞助**：
  * 支持项目长期的全职/核心维护投入；
  * 用于支付 Apple Developer、Microsoft Store 等应用商店年费与代码签名证书；

* **社区联合与生态推广**：
  * 联合技术宣发、官方文章/案例推介、自媒体与开源布道合作；
  * 共同举办开发者活动、社区交流与产品生态联动。
* **基础设施与关键资源支持**：
  * 面向官方演示站（demo.edgeever.org）的高可用算力、对象存储（S3/OSS）及全球加速 CDN；
  * 自动化构建流水线与真机测试集群资源；
  * 优质的 AI 模型 API 接口调用额度。
* **专业工具与平台订阅**：
  * 核心开发工具、分析服务、安全审计与平台专业版订阅支持。
