# 笔记本公开分享站点改造方案

[English](public-notebook-site-plan.md)

关联：[Issue #591](https://github.com/tianma-if/edgeever/issues/591)。更新日期：2026-10-21。

状态：R01～R13 已实现。站点配置在笔记本分享弹窗中展开，原笔记页控制逐站点展示，首页使用独立搜索选择器。本地及独立 Cloudflare 验收见[实施清单](changes/2026-10-21-public-notebook-site.zh-CN.md)。代码基线为官方 `5d1a0661`；历史消融使用 `4ad082b5`，实验材料与产品验收分别记录。真实爬虫、原生真机和 Docker 容器仍未验收。

## 1. 设计选择与边界

**采用当前站点的逐篇排除开关：新增一张排除关系表，并扩展 `notebook_shares` 的两个字段。** 作者在分享设置中选择不对本站访客开放的笔记，章节仍按现有顺序或标题/数字自然排序。保留实时分享，不增加审核、发布快照或站点搭建器。

逐站点排除是分享与笔记之间的关系，与分类标签独立。保留所需的最小关系表，不增加手动排序或通用条目覆盖模型。历史标签实验只证明筛选可行，不作为当前排除模型的验收。

最终行为与边界：

- 原笔记分享弹窗及笔记列表右键菜单按所属站点展示开关，逐篇排除或恢复。排除仅作用于当前分享；父站点、独立子站点各自配置，不改变笔记内容、标签或其他分享的访问规则。默认没有排除项，旧分享的公开范围不自动变化。
- 保留现有顺序及标题/数字排序，不提供站点专属拖拽顺序，也不改作者原有笔记本层级。
- 站点名称来自根笔记本名称，简介来自当前可见首页或文章摘要；不提供独立的名称、简介覆盖设置。
- 复用设备现有主题偏好。公开站点与同源应用使用同一个本机外观选择，不写入作者账号。
- 首版保留服务端元数据和收录开关；完整正文 SSR、sitemap 延后。这会减少无 JavaScript 爬虫的正文可读性和主动发现入口，不宣称与原方案的 SEO 效果等同。

主要价值不变：改善长文阅读、正文检索和站点外观。主要风险仍是公开范围过滤遗漏、收录策略错误及旧服务回滚后忽略新策略。当前交付包括方案、保留的历史实验材料和产品实现；旧数据迁移兼容已在本地验证，独立 Cloudflare 验收库也已执行0001～0072。

## 2. 13 项需求的最小实现

| R02 | 深色模式 | 复用现有 ThemeProvider 与 `edgeever.theme`，提供浅色、深色、跟随系统三选项，不另建主题状态和存储键。正文、代码和画板使用同一有效主题。 |
| R03 | 代码块增强 | 复用复制与高亮，只补语言标识和折叠；折叠后仍复制完整源码，不保存折叠状态到数据库。 |
| R04 | 站内链接预览 | 保留按需的轻量标题、摘要接口，悬停和键盘聚焦都可用。取消预览既不满足需求，也不能用全量正文预取替代。 |
| R05 | 图片与画板 | 复用图片灯箱、手势缩放、X6 自适应及阅读器。补单击放大入口、适应窗口和全屏，不再建设第二套查看器或重复的重置工具。 |
| R06 | 正文全文检索 | 复用现有 FTS、中文匹配及文本摘要能力，支持快捷键、命中高亮、分页和失败反馈。标题过滤不能替代正文搜索。 |
| R07 | 标签聚合 | 点击文章标签，使用同一个搜索接口按标签过滤，可叠加关键词。不增加全站标签云、计数或独立标签聚合接口。 |
| R08 | 自定义首页 | 保存一个首页笔记 ID；始终保留目录入口。首页隐藏、删除或移出范围后回退目录，不返回它的标题或摘要。 |
| R09 | 不公开笔记排除 | 作者显式设置“从此站点排除”，服务端统一拒绝通过本站读取该笔记。默认无排除项；不增加全局草稿状态，也不使用 `#draft` 标签控制公开范围。 |
| R10 | 自定义排序 | 选择 Issue 允许的标题/序号方案。一个站点级 `sortMode` 控制现有顺序或标题自然排序；数字按 2 在 10 前排列，同名用 ID 稳定排序。 |
| R11 | URL 别名 | 保留实例内唯一别名、原 Token 链接和同一撤销边界。别名只解析身份，不新增访问授权。 |
| R12 | 站点外观 | 保留 HTTPS Logo 地址、结构化页眉外链和纯文本页脚，放在小型配置对象中。不增加资产上传服务或任意 HTML。 |
| R13 | SEO 与社交卡片 | 保留显式收录开关、服务端 HTML head、canonical、OpenGraph / Twitter Card。正文继续用现有 SPA 渲染，完整 SSR 和 sitemap 不列入首版交付。 |

桌面保留顶部导航、左侧章节、中间正文和宽屏右侧大纲；移动端通过抽屉访问章节与本文大纲。继续使用现有文章、图片、画板、作者字体/字号/行距/配色及过滤后的正文 CSS。Tooltip 和 HoverCard 支持键盘，定位尊重减少动态效果设置。

自然排序使用统一的 `Intl.Collator('zh-CN', { numeric: true, sensitivity: 'base' })` 帮助函数，分别排列同一父章节下的同类条目，目录、首页目录和前后篇共用结果。排序只改变站点展示；正文和原笔记本顺序不被改写。

## 3. 数据与接口的收敛方案

### 3.1 两个站点字段和一张排除表

| 表与字段 | 类型及默认值 | 用途 |
| --- | --- | --- |
| `notebook_shares.site_slug` | `TEXT NULL` | 可选别名；对非空 `lower(site_slug)` 建唯一索引，保存时统一为小写字母、数字和连字符。 |
| `notebook_shares.site_settings_json` | `TEXT NOT NULL DEFAULT '{}'` | 站点级小型配置，数据库约束为合法 JSON 对象；接口限制合并后的配置不超过 16 KiB。 |

新增 `notebook_share_excluded_memos`，只保存被排除的笔记：

| 字段 | 约束与用途 |
| --- | --- |
| `share_id` | `TEXT NOT NULL`，外键引用 `notebook_shares.id`，分享删除时级联删除。 |
| `memo_id` | `TEXT NOT NULL`，外键引用 `memos.id`，笔记物理删除时级联删除。 |

以 `(share_id, memo_id)` 为复合主键，并为 `memo_id` 建索引。存在记录表示本站排除，取消排除直接删除记录，不增加布尔列、章节类型、排序或版本字段。没有记录仍须通过原有工作区、实时子树和删除状态检查，并不代表无条件公开。

设置排除时校验作者的分享管理权限、笔记所属工作区、实时子树及删除状态。笔记移出或软删除后，由实时范围检查拒绝访问；保留的排除记录在笔记恢复并重新进入范围时继续生效。撤销并重新创建分享使用新的分享 ID，不继承旧排除项。

站点配置对象只包含以下六项，禁止放入逐篇笔记列表、手动排序映射或正文：

| 配置键 | 默认值 | 行为 |
| --- | --- | --- |
| `homeMemoId` | `null` | 首页笔记；显式选择时校验本站排除记录，每次公开读取再次校验。 |
| `logoUrl` | `null` | HTTPS 图片地址；加载失败回退现有图标。 |
| `headerLinks` | `[]` | 文字与 HTTPS 地址组成的外链数组。 |
| `footerText` | `''` | 页脚纯文本。 |
| `allowIndexing` | `false` | 有效收录条件始终是显式允许且当前无密码。 |
| `sortMode` | `'existing'` | 只允许 `existing`、`title`。已有偏好默认不变化。 |

不再增加独立 `site_title`、`site_description`、`home_memo_id`、Logo/导航/页脚列、收录列、排除标签列和两种排序列；排除表只维护本站与笔记的关系，不建立通用条目覆盖表。名称使用现有根笔记本名称，描述使用可见首页或文章的现有摘要；没有首页时使用根笔记本名称。

`homeMemoId` 的无效引用只涉及一个固定大小的指针。移出、软删除或物理删除后，读取时回退目录，不依赖外键或新增清理任务，也不在公开 GET 中改写数据库。工作区和实时子树校验继续由共享服务执行。

配置通过数据库内 `json_patch` 部分更新，保留其他字段；复用 `updated_at`。设置或重置密码时，把 `allowIndexing` 写为 JSON `false`；取消密码不自动重新开启。密码散列、密文、Token 和 Cookie 路径保持现有含义。

正文、标签、搜索和资源继续复用 `memos`、`memo_contents`、`memo_tags`、`memo_search_documents`、`memos_fts` 和 `resources`。方案基线的迁移截止 `0071`；实现新增 `0072_public_notebook_sites.sql`，没有修改旧迁移。

### 3.2 新增八个 API 操作，其余复用

| 接口 | 处理 |
| --- | --- |
| 现有 `GET /api/v1/notebooks/:id/share` | 扩展返回作者可管理的站点配置，不新增另一个站点 GET。 |
| 现有分享创建、撤销、密码 PATCH | 保留语义；密码 PATCH 继续只执行密码操作，不把配置保存混入密码重置分支。 |
| `PATCH /api/v1/notebooks/:id/share/site` | 新增。只保存别名及部分站点设置，返回合并后的配置，不生成或清除密码。 |
| `GET /api/v1/notebooks/:id/share/excluded-memos` | 保留首版接口，分页返回作者可访问的排除笔记 ID 和标题；当前界面不单独展示此列表，不返回完整正文或把列表塞进站点配置。 |
| `GET /api/v1/notebooks/:id/share/memos` | 保留作者关键词/状态过滤后分页接口，当前只供首页选择器读取未排除笔记，不再渲染独立内容管理列表。 |
| `GET /api/v1/memos/:id/notebook-sites` | 新增。返回当前用户笔记所属的有效直接/祖先站点名称、笔记本ID和各自排除状态；不返回正文、密码或Token，不创建分享。 |
| `PATCH /api/v1/notebooks/:id/share/memos/:memoId` | 新增。接受 `{ excluded: boolean }`；设为 `true` 时幂等写入排除关系，设为 `false` 时幂等删除，返回该笔记在本站的排除状态。 |
| `GET /api/public/notebook-shares/:token/search` | 新增。关键词、标签、分页共用一个接口，返回标题、命中摘要及高亮信息；章节路径由现有目录构造。 |
| `GET /api/public/notebook-shares/:token/memos/:memoId/preview` | 新增。按需返回标题和现有短摘要，不读完整正文，不把摘要附到每一条初始目录。 |
| `GET /api/public/notebook-sites/:slug/resolve` | 新增并明确此前遗漏的身份解析操作。只返回 `{ token }`，然后使用原 Token API 及密码门禁；不返回受保护站点的名称、正文或设置。 |
| 现有公开目录、正文和资源接口 | 返回必要的访客配置，统一执行实时范围和逐篇排除。排除笔记列表不下发给访客。 |

逐篇排除使用独立的读取和修改操作，避免扩大站点配置 JSON。原笔记页读取其对应站点的准确状态，不扫描笔记目录或用多页排除列表猜测。仍不增加通用条目覆盖模型、手动排序 PUT 或独立站点 GET。已有解锁 Cookie 绑定在原 Token API 路径，别名仍回到同一路径读取内容，不改变密码协议。

### 3.3 必须保留的服务边界

- 统一过滤工作区、实时子树、删除状态及当前分享的排除记录，覆盖目录、正文、附件、搜索、预览、内部链接、首页和元数据。搜索先过滤再分页；共享服务执行过滤，不依赖浏览器隐藏。标签继续用于分类和搜索，不承担发布控制。
- 搜索直接使用现有全文索引和中文匹配，不建设客户端全站索引，不下载全部正文做筛选。正文链接继续只解析本站当前可见目标，不借独立分享绕过本网站点策略。
- 复用现有 30 秒刷新和查询失败处理，不新增轮询、WebSocket、站点版本或事件总线。下一次服务端请求必须拒绝失效目标；客户端在收到失效响应或刷新时清理视图，不承诺瞬间收回已经下载的文本。
- Cloudflare 与 Docker 共用过滤和 HTML 元数据服务，只保留读取模板、静态资源和运行入口适配。单篇分享和公开表单继续保持原有策略。

### 3.4 收录的最小边界

只有无密码且显式允许的站点别名页面可以收录；Token 页面保留共用的完整 noindex 策略，已配置别名时 canonical 指向别名。密码站点的初始 HTML 始终只有通用分享信息。默认禁止收录，JSON API 继续禁止收录，页面与 API 继续 `private, no-store`、`no-referrer`。前端在选中文章请求完成前保留服务端 robots；失败或禁止收录时使用共用的完整策略。其他分享类型保持原有策略。

服务端初始 HTML 输出转义后的 title、description、canonical 和社交卡片元数据。不可访问文章返回真实不可用状态与禁止收录头；Logo 可用时用于卡片图片，否则使用现有品牌资源，不建设截图生成服务。

正文沿用 SPA 是取舍，不是相同 SEO 效果的实验证明。[Google 文档](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)说明其可以渲染 JavaScript，也说明不是所有爬虫都能执行 JavaScript；允许收录的原始响应不能先带 noindex 再靠前端删除。[Open Graph](https://ogp.me/)元数据放在初始 head 中。[sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview)可以改善发现，但本轮没有实际爬虫证据要求建设它，因此延后；不承诺所有文章已经或必然被收录。

### 3.5 作者分享与站点管理

笔记本右键和更多菜单固定使用“分享笔记本”。已直接分享的笔记本常显更多按钮，打开后复用原链接及Token，可复制链接、设置密码或原地展开“进阶设置”；个人中心保留汇总入口。进阶设置默认收起，包含首页、Logo、外链、排序和收录等整体配置，折叠/重新展开保留未保存输入。分享弹窗不展示笔记管理列表。

逐篇控制放在原笔记页的分享弹窗及列表右键子菜单中，以“在「名称」站点中展示”表达范围；父、子笔记本站点分别显示，修改立即生效，不影响其他站点或单篇分享。读取失败时显示错误与重试，写入失败保留原状态。打开分享弹窗不再自动创建单篇分享，必须明确点击“创建单篇分享链接”，已有链接仍可复制、设密码和撤销。

配置显式保存；首页通过独立搜索选择器选择当前未排除笔记，也可使用目录首页。关闭选择器返回分享弹窗。选择器每页替换显示20条，支持正文关键词，不展示第二份内容管理列表。历史 `/notebooks/:notebookId/site` 地址保留直接访问及刷新，分享弹窗不再跳转到该页。本次修订不增加表或字段。

### 4.1 已执行的对照

在实际 `0001`～`0071` Migration 建出的内存 SQLite 上，**26 项模型检查通过，另复现 3 个删除后失败的反例**。检查包括两字段/零新表、旧行字段保留、标签过滤、正文和中文子串搜索、标签组合、自然排序、首页移动及删除回退、配置部分更新、别名唯一性、密码与收录策略、元数据转义及负载大小。

三项反例分别是：去掉服务端排除后返回草稿；仅保留标题搜索丢失正文命中；先分页再过滤导致明明有可见命中却返回空页。这些行为应保留，不能为了精简而删除。

旧标签方案的固定样本中，站点配置在关联 100/1,000/10,000/50,000 篇笔记时均为 256 字节。这是旧配置编码大小对照，不是当前六项配置的测量，也不是五万篇笔记的运行或性能验收。当前排除关系单独按行保存，行数随排除笔记数增长。

| 合成负载 | 1,000 篇 | 10,000 篇 |
| --- | --- | --- |
| 基础目录 JSON | 123,894 字节 | 1,248,895 字节 |
| 每条目录都附短摘要 | 229,894 字节 | 2,308,895 字节 |
| 一次按需预览 | 125 字节 | 125 字节 |

同一合成长文的完整正文响应为 210,140 字节。因此保留轻量预览接口有实际负载依据，删除它会把开销转移到初始目录或完整正文读取。数值是未压缩 JSON，未测真实请求数、压缩、网络时延或用户悬停习惯。

上一轮[脚本](../scripts/public-notebook-site-schema-ablation.mjs)及[原始结果](public-notebook-site-schema-ablation.json)保持原样，19 项公共场景和 12 组计时没有因本次审查重复运行；其中“一张覆盖表优于两张”的结论只在保留逐篇状态时适用。

### 4.2 需求映射和设计判断

## 5. 实施与最小验收

| 阶段 | 交付 | 验收重点 |
| --- | --- | --- |
| 1. 阅读 | 大纲、复用主题、代码块、图片与画板交互 | 一个真实桌面/手机阅读流程覆盖定位、复制、缩放、键盘及焦点恢复；没有数据库改动。 |
| 2. 配置与发现 | 两字段及排除表迁移、排除笔记管理、自然排序、首页、搜索、预览及设置保存 | 旧分享升级和作者设置到匿名读取完整流程；验证真实访问边界和中文检索。 |
| 3. 外观与公开页面 | Logo/导航/页脚、别名、初始元数据与收录开关 | 原 Token、别名、密码及原始 HTML 策略一致；两个运行时只补入口差异验证。 |

实现后围绕三条实际流程验收，不默认叠加每个组件的单测、全套集成和多轮审查：

1. **旧版本升级与阅读**：固定真实旧数据及预期公开内容，迁移后验证原 Token、密码和解锁授权；在实际页面完成长文、代码、图片和画板操作。布局可以变化，原公开范围不能因默认设置变化。
2. **编辑到访客读回**：作者排除一篇笔记，验证目录、直达正文、附件、搜索、预览、内部链接、首页和元数据均不泄露该笔记；取消排除后恢复正常读取。普通标签修改不得改变排除状态；同一篇在独立子分享中仍按子分享自己的配置处理。用同一组数据覆盖移入移出后排除仍生效、删除级联、撤销重建、管理权限及工作区边界。检查标题数字排序和过滤后分页，不用仅有 HTTP 200 作为完成证据。
3. **别名和收录**：验证别名冲突、解析、原 API Cookie 解锁和 canonical；直接请求 HTML 检查元数据、状态码及隐私。共享服务验证复用，Cloudflare/Docker 各检查入口与响应头；不把构建通过当作爬虫验收。

优先复用现有测试和仍适用的结果，只为具体缺口补检查。必要的 `bun run typecheck`、`bun run typecheck:mobile`、`bun run build:web` 在相关前提变化时运行；不为文档或未变输入重复执行。Android 原生调测若涉及，必须使用 USB 真机，不能用模拟器替代。

迁移只新增列、排除表及相关索引，先迁移再部署服务，不重建分享或轮换 Token；排除表初始为空。备份数据库及现有密码加密根。阶段 1 可回退展示提交；启用逐篇排除后，旧服务忽略排除表会重新公开内容，回滚必须保留过滤逻辑或先撤销受影响站点。关闭收录不能保证外部索引立即消失。
