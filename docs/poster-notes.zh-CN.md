# 海报笔记

[English](poster-notes.md)

通过「更多类型 → 海报（Beta）」创建可编辑海报。在普通笔记操作菜单选择「制作海报」，会用标题及选中文字（未选中时取正文前 240 字）创建独立海报笔记，原笔记保留。

Web 和桌面端打开独立设计工作台，提供 46 套真实模板、12 种平台画幅、内置的中英文字体、主标题／副标题／标签自动排版及真实渲染的模板预览。版式引擎改编自 MIT 许可的 Qiaomu Design，源码及署名位于 `apps/web/src/lib/poster-design`；字体许可随字体文件提供。转换矢量模板时省略生成的栅格颗粒纹理。

画布支持文字、标签、形状、曲线、手绘和图片；多选、编组、对齐吸附、缩放和平移；图层排序、显示隐藏和锁定；字体排版、描边、阴影、渐变及图片适应／裁切／翻转。可按 1～3 倍输出 PNG、JPEG 或 WebP（每边不超过 8192 像素），复制 PNG 或插入原笔记。直接在画布上编辑文字，模板面板不再提供独立文案表单。应用模板时沿用当前画布文案重新排版，并保留独立添加的元素；撤销可恢复之前的布局。直接编辑元素时保留当前排版。

AI 统一使用通用助手右侧栏，海报工作台不再提供独立 AI 面板。Agent 通过 `get_poster` 和 `update_poster` 读取画布、修改文案、配色、字体排版及元素位置，沿用现有 Agent 操作流程。修改保留未指定和已锁定的元素，版本过期时拒绝覆盖；Agent 修改后由编辑器重新生成预览。本功能不生成图片。

## 源稿与保存

`PosterDocument` 是经过校验、有版本号的源稿，与 Fabric.js 状态分离。源稿保存在 Markdown 的 `edgeever-poster-v1` 注释中，可读文字和 PNG 预览用于通用查看。图片元素引用工作区附件编号，不接受任意 URL 或任意 Fabric 对象 JSON。进入海报编辑器后才加载渲染引擎。

保存沿用笔记版本、内容摘要和编辑会话校验。每个画布版本保存独立的、宽度不超过 480 像素的预览图；仅修改标题等元数据时复用预览。历史预览保留供版本恢复使用，因此附件用量随保存的画布版本增加。源稿保存失败时只清理本次未提交的预览。

草稿在当前设备备份。草稿基于另一版本时，需要先下载并核对，不能静默覆盖当前笔记。添加图片和保存新预览需要联网；离线修改保留为本机草稿。插入原笔记时校验其当前版本，并把成品作为原笔记自己的附件保存。

## 兼容与上线

Android 和 iOS 展示可读预览与文字，并禁止把海报当作普通富文本编辑。API 同样拒绝旧客户端丢失海报源稿的保存请求。该门禁需要更新后的服务器；旧客户端连接旧服务器时没有这个保护。通用 MCP `update_memo` 不能替换海报内容。

不需要数据库迁移，也没有修改认证或升级配置。回滚界面时撤下新建／编辑入口，保留源稿、附件与只读保护；不要把海报转换为普通笔记或删除源稿标记。

验证覆盖源稿往返、格式校验、预览保存失败、SQLite 中的版本冲突与旧 contentJSON 覆盖请求、移动端读取策略，以及本地 Web 新建／编辑／保存／重开／导出与插回原笔记。原生硬件、已安装桌面端跨版本链路与付费 AI 生图仍需单独进行发布验证；本功能不实现生图。

浏览器渲染回归页：运行 `bun run dev` 后打开 `/tests/poster-design.html`，检查每套模板在 12 种平台画幅下的渲染、源稿往返、多选变换及 AI 文字对比度。
