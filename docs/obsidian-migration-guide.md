# Obsidian 笔记迁入指引

[简体中文](obsidian-migration-guide.md) | [English](obsidian-migration-guide.en-US.md)

EdgeEver 原生支持将你的整个 Obsidian 知识库（Vault）直接导入。在 Web 网页端或 Electron 桌面端中，**无需手动转换格式、无需命令行工具，也无需编写脚本**，即可通过图形界面将 Obsidian Vault 目录或 ZIP 压缩包一键平滑迁入。

---

### 原生导入支持特性

- **目录树层级还原**：自动根据 Vault 内文件夹层级创建 EdgeEver 嵌套笔记本，完整还原既有知识体系。
- **Front Matter 元数据解析**：自动读取 YAML Front Matter 中的 `title`、`tags`，以及创建时间（`created` / `createdAt`）与更新时间（`updated` / `updatedAt`），精准还原历史时刻与标签。
- **本地图片与附件自动转存**：
  - 支持标准 Markdown 图片链接：`![描述](相对路径/image.png)`
  - 支持 Obsidian 原生维基双链嵌入语法：`![[image.png]]` 或 `![[附件.pdf]]`
  - 附件自动在客户端解析并上传至 EdgeEver 安全资源库，并在正文中转换为对应资源链接。
- **安全过滤与干净迁移**：自动忽略 Obsidian 内部配置目录（`.obsidian`）、版本控制目录（`.git`）、回收站（`.trash`）及系统隐藏文件，不污染知识库。
- **本地流式处理**：所有文件解析均在浏览器/桌面端本地完成，不会将未确认的完整 Vault 整包上传到服务器。

---

### 迁移步骤

#### 步骤 1：准备 Obsidian Vault 数据

你可以选择以下两种方式之一准备数据：
- **方式 A（推荐）：直接选择 Vault 文件夹**。找到你存放 Obsidian 库的本地文件夹即可。
- **方式 B：打包为 ZIP 压缩包**。如果需要在远程或浏览器端操作，可将整个 Obsidian Vault 文件夹压缩为 `.zip` 文件。

#### 步骤 2：在 EdgeEver 中打开导入入口

1. 打开 EdgeEver 网页端或桌面端并登录。
2. 点击左侧底部导航栏的 **设置（Settings）** 图标。
3. 在设置页面的 **导入与导出** 区域中，找到 **从其他应用导入** 卡片，点击 **开始导入**。

#### 步骤 3：选择来源并载入 Vault

1. 在导入弹窗中，来源应用点击选中 **Obsidian**。
2. 添加你的 Vault 数据：
   - **拖拽**：直接将 Vault 文件夹或 `.zip` 压缩包拖入弹窗中心的虚线区域。
   - **浏览选择**：点击 **选择文件夹** 选取你的 Vault 本地目录，或点击 **选择文件** 选取对应的 `.zip` 归档。

#### 步骤 4：本地安全预检与指定目标

1. 载入后，EdgeEver 会在本地快速扫描所有 Markdown 笔记与引用的媒体资源。
2. 预检面板将呈现统计结果：
   - 即将生成的 **笔记本数量**、**笔记篇数** 与 **附件数量**。
   - 目录结构树预览。
   - 若存在同名文件引用歧义或缺失附件，预检列表会清晰标出提醒。
3. 在「导入位置」中，选择将数据 **创建为顶层笔记本**（默认），或挂载到已有的某个父笔记本下。

#### 步骤 5：确认导入并流式写入

1. 确认预检信息无误后，点击右下角 **确认导入**。
2. EdgeEver 将在本地对笔记正文与附件进行流式解析、创建与上传：
   - 界面实时显示处理进度及当前处理文件。
   - Electron 桌面端导入时会自动挂起后台同步，导入完成后自动恢复同步并刷新工作区。

#### 步骤 6：核验导入结果

1. 导入完成后，在弹窗中可以浏览导入结果列表，点击 **打开笔记** 快速核验笔记内容、图片嵌入与标签。
2. 若有个别附件因网络波动未能上传成功，点击 **重试未完成步骤** 即可进行增量重试，不会产生重复笔记。
