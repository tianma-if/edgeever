# Web request budget audit — 2026-11-19

Applies to shared Web/desktop renderer code and the common Cloudflare/Docker API, without Demo-specific conditions.

| Area | Finding and change | Verification |
| --- | --- | --- |
| Startup/sync | Queue-count changes recreated the refresh callback and reran the initial manual sync. A second startup timer also pulled again. Subscribe once per account/instance, read current callbacks through refs, and remove the duplicate timer. | 100 callback/queue rerenders produce one startup refresh; focus/pageshow coalesce; scope changes refresh; queue writes still upload. |
| Plugin catalog | Catalog reconciliation resolved GitHub releases and downloaded packages only to obtain the bundled official publisher/id list. Read the bundled registry for this trust decision. | Plugin host/catalog/trust and community revocation tests. Actual package installation keeps checksum verification. |
| Plugin updates | Workspace startup, host activation and marketplace UI independently resolved the same official catalog; every focus could check packages again. Cache successful public resolution for 60 seconds with in-flight deduplication, scoped by registry URL, instance and transport. Throttle automatic release/package checks to five minutes; retain immediate catalog enable/disable sync on focus and explicit marketplace refresh. | 20 concurrent marketplace readers perform one lookup; explicit refresh and different registry keys make new requests. Errors are not retained. |
| GitHub proxy | Concurrent cache misses duplicated upstream manifest downloads. Share in-flight requests using existing repository/lookup-type keys. Immutable asset IDs now return browser-private one-day immutable caching; mutable release tags retain five-minute caching. | 20 concurrent manifest requests produce one GitHub fetch; different repositories remain separate. This reduces upstream work; only browser cache hits avoid Worker invocations. |
| Attachment size | Unknown sizes required a one-byte object read. A workspace-authorized, uncached metadata endpoint uses existing indexed resource/pending-resource lookups without opening R2/S3/filesystem objects. Known sizes and existing per-page deduplication remain in use. | Workspace/scope denial and cross-workspace 404; zero object reads; real local browser returns size metadata. Old servers fall back on unsupported-route 404/405; missing-resource, auth, rate-limit and server errors do not trigger another download. Non-Web/external URLs retain the existing range path. |
| Sync database reads | Incremental sync already uses workspace/cursor indexing and skips detail reads for empty changes. Bootstrap continuation already opts out of full counts/catalog aggregation. Preserve this protocol. | Local SQLite snapshots of 401/1,201 notes use 3/7 pages and 8/16 statements: one count and one notebook aggregation for the whole operation, not per page. No production scans or load tests. |

The five-minute visible-workspace polling interval, cross-tab lease and incremental cursors are unchanged. Retry queues already honor per-operation backoff; no blanket JSON API cache or private attachment-content cache was added. Plugin catalog and community revocation checks remain separate from cached public release metadata.

Compatibility: old clients continue using the existing blob route; new clients fall back when an old server lacks metadata. The metadata route uses the same workspace resource lookup and permissions as blob downloads, with no database migration. Public marketplace freshness may lag by up to 60 seconds between explicit refreshes (the proxy's existing manifest cache remains five minutes). Revert this change and redeploy to restore prior request scheduling; no data migration or credential reset is required.

Validation: full non-E2E suite, targeted plugin/lifecycle/cache/resource/sync tests, both required typechecks and Web build. Local browser checks cover workspace rendering, displayed attachment sizes and authenticated metadata; production traffic savings are not claimed from synthetic counts.
