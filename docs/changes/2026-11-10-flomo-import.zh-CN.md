# flomo 原生导入

[English](2026-11-10-flomo-import.md)

## 目标与范围

关联 [#794](https://github.com/tianma-if/edgeever/issues/794)，本次只实现 flomo，不自动关闭包含其他来源的 Issue。基于现有第三方导入框架增加 flomo HTML ZIP 来源，复用 Worker、索引、预检、分片资源上传、进度、取消与重试，不另建入口或执行器。

## 允许变更与现行决定

- 支持官方 HTML ZIP（也可使用统一入口选择解压后的文件/目录），读取正文、标签、创建时间、图片、音视频及本地附件；HTML 只在不可执行 DOM 中解析、转换，不加载为页面。标签保留行内、相邻及完整层级名，去掉末尾斜线，排除 URL 锚点和键帽 emoji，不派生父级标签。
- 导出时间按当前系统时区解释，不提供时区选项。导出没有更新时间，沿用框架缺失时间的提示与导入时间行为。
- 重新选择 ZIP 建立新任务始终新增，包括同一 ZIP 重复导入；同一任务内重试仅补未完成步骤，复用现有任务标识，不覆盖外部编辑。
- 完整采用统一流程：预检错误阻止整批；运行失败停在失败条目并保留已写数据供手动重试；关闭窗口后继续，可重新查看进度；明确取消沿用框架行为。在用户选择的位置下创建 `flomo` 笔记本。
- 复用当前框架的元数据、标签数量、附件大小和账户/实例一致性契约，不改变其他来源的行为。新增 flomo 格式至现有能力响应及格式校验，不新增后端导入协议或数据库迁移。
- 优先复用现有 HTML 转 Markdown 转换器，允许提取到共享模块并使用仓库已有的 DOM/转换依赖；HTML 扫描与转换在 Worker 中执行，逐条正文写入索引，Worker 使用模块拆包及来源解析器按需加载，保持现有资源预算；附件使用既有分片读取和上传，避免主线程整包转换及整组附件驻留。
- 同步中英文迁移指南及导入目录文案。验收覆盖真实导出、重复新任务、同任务失败重试、预检阻断、媒体内容一致性及大包响应；截图与详细材料不提交 Git；关键截图作为 GitHub 附件嵌入 PR。

原独立入口方案的“有效条目继续、失败自动删除、离开页面停止、直接写入所选笔记本”被上述统一行为替代。原因是主干已具备成熟导入框架，统一交互及恢复语义，避免维护第二套机制。此前独立入口的结果只作为解析样本证据，不能替代此次集成验收。

## 不变边界与风险

不实现 Notion/思源来源、不修改其他导入器行为、不新增自动重试、不扩展数据库结构、不发布或部署生产。风险为正文/附件遗漏、时区错误、恢复语义或其他导入器回归；回滚代码可停止新能力，但不能撤销已写数据。使用隔离本地实例验收，保留真实云端额度及大批量远端吞吐的未验证边界。提交前按项目规则核对理解，PR 不自动合并。

## 完成核对

已按统一框架完成实现，差异与上述范围一致。导入相关测试 88 项通过，Web/API 类型检查、移动端类型检查、Web 构建、语言目录检查及 Web 性能预算检查通过。真实 flomo 导出每批 5 条、2 个附件，重复新任务均新增；关闭对话框后继续并可重新查看结果。图片和视频下载摘要与原始导出一致，视频可播放。37 条复杂样本出现 2 个预检错误，整批阻止；集成测试覆盖运行失败保留部分数据及同任务重试恢复。

生产构建 Worker 扫描 5,000 条笔记约 5.9 秒，主线程 16ms 定时器最大间隔 17.3ms；初始模块预加载 782,805 字节，低于 819,200 字节预算。模块 Worker 调整后的图片压缩也已验证。HTML 仍整体解析为 Worker 内 DOM，未证明任意大小单文件的内存上界。真实 Cloudflare 额度和远端大批量吞吐未验证；本地结果不替代云端验收。截图及详细报告保留本地，不纳入 Git。
