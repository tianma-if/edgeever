# 图片画廊适应方式

每个图片画廊的列数控件旁新增了**适应宽度**和**适应高度**。适应宽度保留原有的裁剪展示效果；适应高度会在大小一致的单元格内完整显示每张图片，包括竖图的顶部和底部，剩余空间留在图片两侧或上下。设置只影响当前画廊，并支持撤销和重做。

富文档在画廊节点中保存 `fit: "width" | "height"`，缺失或不支持的值使用适应宽度。HTML 带有 `data-image-gallery-fit` 属性，供编辑器、公开分享、HTML 导出及打印样式使用。Android/iOS 共用的画廊工具栏也提供这两个选项。图片卡片导出原本就完整显示图片，本次保持该行为。

适应高度的画廊在普通 Markdown 图片外增加 `<!-- edgeever:image-gallery fit=height layout=… -->` 和 `<!-- /edgeever:image-gallery -->`，以便修改其他 Markdown 内容后仍保留适应方式和列数。其他 Markdown 阅读器仍能显示图片。如果在标记内插入文本，EdgeEver 会保留编辑后的内容并拆分画廊。默认的适应宽度画廊继续使用原有的普通图片 Markdown 投影。

本次无需数据库迁移或新增依赖。回退功能提交即可回滚实现；旧客户端可能忽略适应方式属性并显示原来的布局，旧 Markdown 解析器不会将注释保留为画廊设置。应验证 Web 布局、保存重开、Markdown 编辑、只读视图、导出及窄屏。宣称原生端视觉一致前，仍需完成 Android USB 真机及 iOS 真机验证。
