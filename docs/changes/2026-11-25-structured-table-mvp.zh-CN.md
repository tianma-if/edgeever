# 多维表格 MVP：字段、视图布局、记录详情与 CSV 导入

## 问题与目标

现有结构化表格只有单视图（筛选 + 排序）和 7 种字段类型，行数与字段上限内可用，但缺实际办公所需的最小能力：无法按单选/复选/日期分组、无法隐藏或加宽列、无法用看板浏览同一条记录、无法在窄表里一次看到整条记录、无法把外部 Excel/CSV 数据导进来。目标是补齐这些能力，且不改变笔记与表格的存储模型（表格仍是 memo 内容里的一段 JSON 标记）。

## 允许的变更与验收

- 字段类型新增多选（`multiSelect`）、电话（`phone`）、邮箱（`email`）、自动编号（`autoNumber`）。多选存数组并在 CSV 中用 `; ` 分隔；电话与邮箱按模式校验并参与筛选；自动编号不入库，按行号实时显示，表单与字段配置里不出现。
- 视图文档升级到 schema 3：`NamedTableView` 增加 `columns`（显隐、顺序、80–600 宽度）、`groupBy`（仅 `select`/`checkbox`/`date`，可升/降序）、`layout`（`grid`/`kanban`）。schema 1/2 文档照旧读取；只有保存 v1/v2 无法表达的配置才升级为 v3；无法读 v3 的旧客户端保存会被服务端拒绝，而不是静默丢弃配置。
- 表格工具栏新增「表格 / 看板」切换、「字段配置」与「分组」。字段配置里首个字段不可隐藏、不可上移；分组为空即不分组，看板只对 `select` 字段分组，没有单选字段时弹出分组对话框。
- 记录详情对话框可在一处编辑整条记录：自动编号与附件只读，复选框、单选、多选分别用复选/下拉/复选组，其余用输入框失焦提交。看板卡片与表格行都有展开入口。
- 新增 CSV 导入：按字段名映射，支持带引号、引号内逗号换行、BOM；跳过自动编号与附件列并在结果中列出；无法识别的选项、未知列、重复列、非法邮箱/电话逐行报错并指出行号；超过 1,000 万字符或记录上限时拒绝。导出 CSV 改为只导出当前视图可见列。
- 公开表单支持多选、电话、邮箱字段，仍不展示自动编号；表单写入继续走原有 memo 更新与冲突重试。

## 保持不变

存储仍是 memo 内的 base64url JSON 标记，不新增数据表、不做跨表关联、公式、行级权限、评论与自动化；单表上限仍是 40 字段 / 2,000 记录。筛选、排序、视图切换仍在本机计算，不请求服务端。自动保存延时、编辑会话、修订号与离线队列语义不变。附件字段与移动端只读降级不变。
