# 无标题笔记显示创建日期

[English](2026-11-06-untitled-note-date.md)

关联 Issue：#813

## 问题与结果

此前所有没有标题的笔记都显示为 **无标题笔记**，多条速记在笔记列表、快速切换和引用笔记选择器中看起来完全相同。

现在，Web 端与桌面端的私人工作区会在无标题笔记的名称后显示创建日期和时间，例如 `无标题笔记 · 2026年11月6日 14:32`。日期按查看者的语言和时区显示。显示位置：

- 笔记列表（预览与紧凑）；
- 快速切换（搜索结果）；
- 引用笔记选择器与 `@` 笔记建议。

日期只用于显示名称。已保存的标题不变，从选择器插入的链接仍使用普通的无标题文字。创建时间缺失或无效时，显示普通名称。

**设置 → 常规设置 → 无标题笔记显示日期** 可选择格式：默认、简短、完整、ISO 8601（`2026-11-06 14:32`）、仅日期或不显示（普通名称）。每个选项都附带示例。该选择保存在当前浏览器或桌面应用中（`edgeever.untitledMemoDateFormat`），不会同步。

公开分享页、笔记本站点和 Companion 卡片不变。

  - 真实标题与默认标题；
  - 偏好的保存，包括存储被阻止的情况。
- `NoteLinkSuggestion.test.mjs` 检查插入的链接不包含日期。

  - 默认、ISO 和不显示格式下的列表名称；
  - 快速切换中的名称；
  - 已保存的标题不变。
