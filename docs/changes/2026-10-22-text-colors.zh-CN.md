# 文字和高亮颜色

富文本编辑器在删除线按钮旁新增**文字和高亮颜色**菜单。选中文字或放置输入光标后，可以选择九种文字颜色或九种高亮颜色。两种属性相互独立。选择**默认文字颜色**、**无高亮**或**重置文字和高亮颜色**可以清除对应颜色。代码和只读内容会禁用该菜单。

颜色保存在现有富文本 JSON 中，并以 `<span style="color: #rrggbb; background-color: #rrggbb">…</span>` 行内标记写入 Markdown。共享 Markdown 编解码器可在浏览器和没有 DOM 的 Workers 环境中处理该语法。调色板颜色会在深色模式下调整显示。共享原生编辑器结构会保留这些标记；本次变更不包含原生端颜色选择界面。

验证覆盖选区、光标处输入、独立清除颜色、撤销和重做、保存和重新加载、富文本与 Markdown 切换、键盘焦点、深色模式显示及服务端 Markdown 往返转换。尚未进行原生设备实测。
