| --- | --- | --- |

| 插件更新 | 工作区启动、主机激活和市场界面独立解析同一官方目录；每次聚焦可能再次检查插件包。成功的公共解析结果缓存 60 秒并合并并发，按目录 URL、实例和传输函数隔离。自动版本/包检查限制为五分钟一次，聚焦时仍立即同步插件启停，手动市场刷新仍重新请求。 | 20 个并发市场读取只请求一次；显式刷新及不同目录键重新请求；失败不保留。 |

可见工作区的五分钟轮询间隔、跨标签页租约和增量游标保持原样。重试队列已有逐操作退避；未新增通用 JSON API 缓存或私有附件内容缓存。插件目录及社区撤销检查与缓存的公共 Release 元数据分开处理。

兼容性：旧客户端继续使用原 blob 路由；新客户端在旧服务端缺少元数据接口时回退。元数据接口沿用下载接口的工作区资源查询和权限，无数据库迁移。两次显式刷新之间公共市场解析最多延迟 60 秒，代理既有清单缓存仍为五分钟。回退此变更并重新部署即可恢复原调度，无需数据迁移或重置凭据。

验证：完整非 E2E 测试、插件/生命周期/缓存/资源/同步定向测试、两项规定类型检查及 Web 构建。本地浏览器检查工作区渲染、附件大小显示和已认证元数据；不把合成请求计数当成生产流量节省结论。
