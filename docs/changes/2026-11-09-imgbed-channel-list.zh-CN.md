# ImgBed 渠道名称下拉选择（桌面端）

[English](2026-11-09-imgbed-channel-list.md)

## 问题与结果

跟进 [Issue #822](https://github.com/tianma-if/edgeever/issues/822) 与 [#823](https://github.com/tianma-if/edgeever/pull/823)。#823 新增的"渠道名称"需要手动填写，并与 ImgBed 管理后台中的名称完全一致，容易填错。现在渠道名称改为可输入、可选择的输入框，右侧新增"加载渠道"按钮：读取 ImgBed 的渠道列表后可直接选择，也可以随时手动输入。

## 行为

| 编号 | 行为 | 验收 |
| --- | --- | --- |
| B01 | 填写 ImgBed 地址和 API Token 后，点击渠道名称右侧的"加载渠道"按钮（与输入框同一行），桌面端主进程会用该 Token 请求 `GET /api/channels`，复用现有的地址校验、主机安全检查、超时、禁止重定向和响应大小上限。只转发地址和 Token，不转发其他字段。 | 桌面端 `imgbed.test.mjs`。 |
| B02 | 渠道名称使用与"添加模型"中"模型 ID"相同的可输入可选择组件（由原 `AiModelIdInput` 抽出的通用 `ComboboxInput`）。加载成功后，聚焦输入框会列出所选上传渠道下的全部已启用渠道（顺序与 ImgBed 一致），并高亮当前值（为空时高亮第一项），因此直接回车不会改动已有名称；打字后按输入过滤，过滤后重新展开仍按 ImgBed 原顺序显示；只有输入框会确认选项，在右侧展开按钮上按回车或空格只展开列表，不会改写字段；输入的名称不在列表中时作为最后一项保留。留空即由 ImgBed 选择。切换上传渠道时直接使用已加载的列表；加载期间除渠道名称外的设置、测试连接和保存都不可操作，渠道名称保持可编辑以免丢失焦点；地址按主进程同样的方式解析，只是大小写、默认端口、末尾斜杠或 `/upload` 写法不同时不算改变。 | 人工检查（本地 Web 端模拟接口）。 |
| B03 | 只列出 EdgeEver 能原样发送的名称：去重，并排除首尾带空格、包含控制字符或超过 100 个字符的名称；被排除的数量会返回给设置页，设置页提示用户在 ImgBed 中修改这些名称，而不是显示"没有渠道"。 | 桌面端 `imgbed.test.mjs`。 |
| B04 | 已保存的名称不在列表中时提示重新选择（列表收起时才判断，打字过程中不提示）；有名称因首尾空格、控制字符或超长被排除时，同时提示数量；所选上传渠道下没有已启用渠道时给出说明。 | 人工检查。 |
| B05 | 加载失败时保留输入框和已填写的名称（重新加载失败时保留之前已加载的列表），并说明原因：ImgBed 版本不支持渠道列表（返回 404 或网页）、Token 被拒（401/403，测试连接时显示同一提示），或其他失败（检查地址和网络）。 | 桌面端 `imgbed.test.mjs`；文案为人工检查。 |
| B06 | 测试连接的名称校验与 #823 相同，仍会确认名称存在并以 `autoRetry=false` 写入测试图片。旧版本 ImgBed 的错误同时带 `IMGBED_CHANNELS_UNSUPPORTED:` 和原有的 `IMGBED_CHANNEL_NAME:` 标记，加载其他版本 Web 页面的桌面端仍能识别；新设置页也能识别 #823 版桌面端只带 `IMGBED_CHANNEL_NAME:` 的版本不支持错误；Token 被拒统一使用 `IMGBED_TOKEN_REJECTED:` 标记。测试连接时设置页提示"当前 ImgBed 版本不支持指定渠道名称"，名称不存在时仍提示"渠道名称无效"。 | 桌面端 `imgbed.test.mjs`。 |

## 范围与限制

- 仅桌面端可用。Web 端没有桌面接口，不显示"加载渠道"按钮，渠道名称仍为手动填写。
- 列表在点击按钮时读取一次，不会自动刷新；在 ImgBed 后台增删渠道后需再次点击"加载渠道"。
- 渠道名称的存储格式不变，已保存的设置无需迁移。
- `AiModelIdInput` 被通用的 `ComboboxInput` 取代，"添加模型"的"模型 ID"随之改用该组件。行为保持不变，另有三处小改进：打开列表时先显示全部选项、无可显示选项时不再弹出空列表框、列表滚到底后不再带动外层滚动（`overscroll-contain`）。

## 风险与回滚

只改动桌面端 ImgBed 设置页、预加载脚本和主进程（新增一个只读的 IPC 接口），以及"添加模型"中"模型 ID"使用的组件；不涉及上传链路、服务端、API、存储或 Migration。回滚：回退此改动，渠道名称恢复为手动填写。

未验证：针对真实多渠道 ImgBed 实例读取渠道列表；在桌面端（Electron）中的实际交互，本次仅在本地 Web 端通过模拟接口检查了布局和状态，"添加模型"在本地用模拟的模型列表检查了发现、滚动、点选和回车不提交；德语、西班牙语、法语、日语、波兰语、俄语文案未经母语者审校。
