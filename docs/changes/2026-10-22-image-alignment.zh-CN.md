# 单张图片对齐

在富文本编辑器中选中独立图片，即可选择**左对齐**、**居中**或**右对齐**。对齐方式单独保存在该图片上，并可与尺寸设置配合使用。选中图片的操作按钮在图片下方换行排列，使较小图片的控件也能正常使用。拖动调整尺寸时会保留所选对齐方式，且开始拖动时不会突然改变尺寸。

原有图片在选择对齐方式前保持默认布局。图库继续使用自己的布局控件。显式设置对齐的图片在导入 Markdown 时保持独立，不会仅因相邻而自动变成图库。

对齐方式保存在富文本 JSON 中，并在 Markdown 中导出为 HTML 图片标签，同时保留百分比宽度与通用对齐样式。共享编解码器无需 DOM 即可处理这些标签，包括可折叠详情中的图片。共享及原生图片结构会保留该属性，原生图片视图会应用显式对齐。本次变更不包含原生端对齐选择界面，也尚未进行原生设备实测。
