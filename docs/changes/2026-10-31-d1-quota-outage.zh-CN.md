# D1 日额度耗尽的故障诊断

## 已观察到的故障

2026-10-31，桌面登录界面对 `tianma.edgeever.org` 显示 `http_500`。只读检查发现：`/api/release` 仍报告服务端 2.16.0，`/api/health` 返回 500，未登录会话探测返回 200。失败健康请求的 Worker 日志明确记录 `D1_ERROR: Your account has exceeded D1's free tier daily row read limit`。数据库检查在登录之前失败；这些观察不能确定历史读取由哪项操作产生，也不能证明数据丢失。

此前 Release 的 Demo 部署已经因同一账号级额度错误失败。Release 资产验证并不能证明个人实例可用。更新桌面应用不会部署服务端的读取预算修复。

## 产品改动

识别 D1 明确报告的每日读取或写入额度耗尽错误，包括嵌套原因，返回 HTTP 503 和 `database_daily_quota_exceeded`。Web/桌面登录在全部五种支持语言中显示可操作的提示。其他网络、结构、存储和单次查询错误保持原分类。不向客户端返回底层查询或提供商错误细节。

此修复只纠正诊断，不恢复耗尽额度、不绕过认证、不修改存储、不执行迁移、不部署服务端。跨运行时业务路径保持原状，提供商错误识别仅位于错误处理层。

## 恢复与验证

Cloudflare 说明免费日额度于 UTC 00:00 重置，升级 Workers 通常可在几分钟内解除每日读写限制：<https://developers.cloudflare.com/d1/platform/pricing/>。本次故障的下一重置时间为北京时间 2026-11-01 08:00。付费升级需要所有者明确决定。数据库恢复可查询后，实例仍需按正常流程升级服务端、执行迁移 0084，并验证健康与登录。

定向测试覆盖读写两类额度、嵌套原因、诊断脱敏、其他错误、循环原因，以及登录和会话阶段的提示选择。要求通过 Web/API 类型检查、移动端类型检查和 Web 生产构建。此诊断修复尚未验证线上旧到新服务端升级、生产迁移、付费订阅变更或实际服务恢复。撤回错误分类与提示即可回滚，无需数据迁移。
