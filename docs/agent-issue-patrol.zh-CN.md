# Issue 巡检执行细则

通用规则见 [变更风险评估](../AGENTS.md#变更风险评估)、[GitHub 协作](../AGENTS.md#github-协作)和[巡检共用约定](../AGENTS.md#巡检共用约定)。

## 巡检范围

- 首次检查最近 24 小时新增或更新的 Issue。之后从上次成功扫描位置继续，并复查未结项。
- 已有 PR 覆盖同一问题时交给 [PR 巡检](agent-pr-review.zh-CN.md)。

## 处理规则

- 已确认的低风险 bug 当轮修复，验证通过后提交并推送。提交避开自动关闭关键词。推送后回复提交链接、验证结果和发布状态。
- 高风险或验证不足的改动，等维护者审阅方案后再改。
- 值得做的功能建议给一份方案，实现和排期由维护者决定。

## 状态记录

`issues.json` 分别记录提交、推送和回复进度，保存已读更新时间和评论 ID、分类、关联 PR、待办、修复提交、验证结果和已发回复 ID。
