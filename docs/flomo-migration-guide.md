# flomo 笔记迁移指引

[English](flomo-migration-guide.en-US.md)

1. 在 flomo 网页版或客户端中打开 **设置 → 账号详情**，滚动至页面下方点击全局导出按钮，下载 HTML ZIP。
2. 在 EdgeEver 的 **个人中心 → 备份与导入 → 从其他应用导入** 中选择 **flomo**，选择原始 ZIP（或解压后的目录）。
3. 查看预检结果并选择目标位置，确认后会在该位置下新建 `flomo` 笔记本。存在预检错误时需先处理错误，再重新选择文件。
4. 导入中关闭窗口不会停止任务，可重新打开查看进度。运行失败会保留已写入数据；使用同一任务的“重试未完成步骤”继续，不会再次创建已完成笔记。

**重新选择 ZIP 开始新任务会全部新增，包括同一 ZIP 重复导入；不跨任务去重或覆盖。** flomo 时间不含时区，按导入设备当前系统时区解释。缺失更新时间沿用统一导入提示及导入时间行为。

确认正文、标签、时间和附件完整前，请保留原始导出包。统一流程、限制及可选 MCP 迁移见[完整迁入指南](note-migration-guide.md)。
